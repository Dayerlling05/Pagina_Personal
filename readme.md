
##  Pagina Personal
##  Descripción del proyecto

Página web personal desarrollada con HTML5 y CSS. El objetivo es presentar mis gustos, intereses, pasatiempos y preferencias de entretenimiento mediante un diseño visual atractivo y organizado.

El sitio permite conocer un poco sobre mí, explorar mis películas favoritas, descubrir las canciones de mis artistas preferidos y visitar algunas de las plataformas web que utilizo.

## Objetivos

- Practicar los fundamentos del desarrollo web.
- Utilizar HTML para estructurar el contenido de una página.
- Aplicar CSS para mejorar la apariencia y organización visual.
- Crear una página personal con diferentes secciones.

## Tecnologías utilizadas

- **HTML5:** estructura y contenido de la página.
- **CSS:** estilos, colores, distribución y diseño visual.

## Características principales

### Sobre mí
Presentación personal y descripción de mis intereses.

### Pasatiempos
Lista de actividades favoritas, como la programación, el diseño web, el aprendizaje y el entretenimiento.

### Películas favoritas
Galería de películas y sagas de terror, suspenso, aventura y acción:
- El Conjuro
- La Noche del Demonio
- La Momia
- El Justiciero

### Música favorita
Sección dedicada a mis artistas y canciones preferidas:
- Sebastián Yatra
- Los Bukis
- Álvaro Torres
- Michael Jackson

Cada artista cuenta con enlaces para buscar sus canciones en YouTube.

### Sitios web favoritos
Accesos a plataformas como YouTube, Netflix, GitHub, Facebook, Instagram, Spotify y TikTok.
